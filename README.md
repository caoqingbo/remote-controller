# Remote KeyMapper Lite — 无驱动遥控器键位映射器

一个 Windows 下的轻量 HID 遥控器映射工具，支持蓝牙 / 2.4G / USB 遥控器。
本分支只被动监听 Raw Input，**不安装驱动、不使用键盘钩子、不屏蔽原生按键**。

## 特性

- **无驱动**：只使用 Windows 自带 Raw Input 和 SendInput
- **保留原键**：执行自定义动作时，遥控器原来的功能也会继续执行
- **设备无关**：通过设备路径匹配遥控器，不影响其他键盘和鼠标
- **按键学习**：识别键盘、鼠标按钮和 HID 原始字节
- **丰富动作**：组合键、文本、程序、音量/媒体、鼠标点击/滚轮/移动
- **每键开关**：映射可独立启用、禁用和删除

## 运行要求

- Windows 10 / 11（64 位）
- Python 3.10+（需包含 tcl/tk）
- 不需要管理员权限，不需要 Interception

## 快速开始

```bat
run.bat
```

1. 点「选择设备」，双击遥控器对应的设备。
2. 点「开始学习」，再按遥控器按键。
3. 选择动作类型，填写或录入动作内容，保存映射。

如果之前使用过完整版，请先卸载 Interception 并重启；本轻量版不会自动安装或调用它。

## 动作语法

| 类型 | 内容示例 |
|---|---|
| combo 组合键 | `ctrl+c`、`win+d`、`alt+f4`、`lalt+k`、`esc`、`f5` |
| text 文本 | 任意文字（支持中文） |
| run 运行 | `notepad`、`calc`、程序完整路径 |
| volume 音量 | `volumeup`、`volumedown`、`mute` |
| media 媒体 | `playpause`、`nexttrack`、`prevtrack`、`stop` |
| mouse 鼠标 | `click_left`、`click_right`、`double_left`、`scroll_up 3`、`move 0 50`、`moveto 960 540` |

## 与完整版的区别

轻量版刻意不包含以下能力：

- 不能阻止遥控器原键的默认行为
- 不能拦截或改写其他程序收到的原始键盘事件
- 不能绕过会拒绝 `SendInput` 模拟输入的应用
- 不重启蓝牙设备、不修改配对记录、不注册设备愈合任务

因此，它适合“按遥控器某键，同时额外触发一个动作”的场景。若原键本身会打开浏览器或执行媒体功能，该行为仍会保留。

## 卸载

退出软件后删除本目录即可。如设置过开机自启，请先在界面关闭。
本分支没有安装任何驱动或计划任务。
